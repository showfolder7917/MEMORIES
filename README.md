### 富士通金融系统｜Java开发・品质强化

  参与日本金融核心业务系统开发与维护，覆盖 CP、IT、SB 等多个业务域及公共组件。负责基本设计、详细设计、Java开发（PG）、单
  体测试（PT）、品质强化、规格书维护和生产障害分析，涉及批处理、数据库、金融接口文件。
  负责富士通日本金融系统多个业务工程的设计、开发、测试与品质强化，擅长复杂遗留系统的影响分析和障害定位，能够从规格、代
  码、数据库、接口文件到测试数据完成端到端问题闭环。
  主要成果：
  - 负责多个既存工程的改修与横向影响分析，在复杂遗留系统中实现最小范围修改，避免公共组件变更影响其他业务。
  - 解决规格书、Java代码、数据库定义、接口文件和测试数据长期不一致的问题，建立完整的追踪与验证闭环。
  - 排查批处理异常、数据冲突、数据库序列、条件分支遗漏、空值处理及边界数据问题。
  - 解决固定长文件、CSV、日文编码、全角/半角空格、字节长度及数值格式等金融接口问题。
  - 通过代码审查、静态检查、分支覆盖和回归测试，提高既存系统的可维护性与交付品质。

  前端技术栈：Angular、TypeScript
  后端技术栈:Spring Boot MyBatis REST API＋JSON Gradle
  数据库: PostgreSQL
